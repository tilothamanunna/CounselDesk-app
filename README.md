# CounselDesk

A responsive front-end prototype for tracking University Counsel matters by person, status, priority, due date, type, and owner.

## Files

- `index.html` — app page
- `style.css` — layout and visual styles
- `app.js` — sample matters, filtering, profiles, form editing, activity log, and browser-local persistence

## Preview

Open `index.html` in a browser. The three files must stay together in the same folder.

## Put it in a GitHub repository

1. Create or open your repository on GitHub.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `app.js`, and this `README.md` (or upload the contents of this folder).
4. Commit the uploaded files.
5. To publish it with GitHub Pages, open **Settings → Pages**, choose the branch and root folder, then save. GitHub will provide the published URL.

## Data and security

This is a front-end demo. Matter data is saved only in the current browser using local storage. There is no sign-in, server database, role-based access, audit-grade history, or protected document storage. Do not put confidential legal information in this version or publish real case data in a public repository. A secure production app needs a protected backend and access controls.
